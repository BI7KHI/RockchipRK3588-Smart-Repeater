## 2. 摄像头：开机自动循环录像

### 实现
`app.py` 新增守护线程 `_camera_autostart_worker()`（模块加载即启动）：

```
启动 → sleep 8 s（等 /dev/video21 枚举完成）
     → _cam_loop_ensure('boot')：确保 采集进程 + 分段录像 + 清理线程 都在跑
     → 每 30 s 复检一次，录像进程意外退出会自动重新拉起（heal）
```

- 采集参数变化、保存设置后立即恢复录像（`_cam_loop_ensure('settings-saved')`），不再等 30 s 自愈。
- 手动「停止循环录像」/「停止采集服务」会置 `CAM_LOOP_MANUAL_STOP = True`，**本次运行内不再自动拉起**；
  点「开始循环录像」清除该标记；重启后恢复自动（符合「开机自动启用」的语义）。
- 新增设置项 `camera_loop_autostart`（默认 `1`），页面「高级设置」有对应勾选框。
- `/api/camera/status` 新增 `loop_running` / `loop_autostart` / `loop_manual_stop`。

## 5. BUSY 接收状态（GPIO3_A5 / 全局 GPIO 101）

### 硬件对应
```
P26-36  丝印 GPIO.27   RK3588 GPIO3_A5   全局 Linux GPIO 101
        GPIO3_A5 = 3×32 + 5 = 101        gpiochip3 line 5
```
参照 PTT（GPIO3_A1 → 97）的同一套做法：`elf2-ptt-gpio.service` 开机以 root 导出并 `chown elf`，
新增 `/usr/local/sbin/elf2-ptt-gpio.sh` 同时处理 **PTT=97（输出）+ BUSY=101（输入）**，
udev 规则 `99-elf2-ptt.rules` 也补了 gpio101。

### 软件
- `app.py` 新增 BUSY 模块（只读不写）：常驻线程 `_busy_watchdog()` 每 **0.25 s** 读一次
  `/sys/class/gpio/gpio101/value`，记录触发态、电平沿次数、触发次数、累计时长、最近变化时间，
  并与 PTT 组合判断「自己发射期间仍 BUSY」的自激风险（`tx_conflict`）。
- 接口：`GET /api/busy/status`、`GET /api/busy/diag`、`POST /api/busy/polarity`（管理员）；
  `GET /api/ptt/status` 一并返回 `busy`，总览页 1.5 s 轮询一次即可同时刷新 PTT/BUSY。
- 总览「中继状态」：**BUSY 行 = GPIO3_A5 实时接收状态**（`BUSY 空闲（GPIO101 电平 0，累计触发 N 次）`
  / `BUSY 接收中（Xs）` / 发射期间追加「注意自激」告警）；另加一行「本地录音」表示网页语音输入/发射占用。
- 摄像头实时预览画面右上角也有一个 `BUSY 空闲 / BUSY 接收中` 徽标。
- 设置与校准页新增「BUSY 接收状态（GPIO3_A5 · 全局 GPIO 101 · 输入）」诊断卡片：
  极性下拉（高有效/低有效，一键切换、立即生效）+ 原始电平 / 方向 / 有效极性 / 当前判定 /
  **电平变化次数** / 累计触发 / 最近变化 + 最近 12 条触发事件。

### ⚠️ 实测发现（需要你确认一次硬件）
开板即测：**BUSY 引脚静态电平稳定为 `0`（未触发状态），90 s 内电平变化次数 = 1（只有导出那一次）**。

```
gpio101  direction=in   value=0   owner=elf
原始电平 0 · 方向 in · 电平变化次数 1 · 最近变化 61 s 前
```

由此确定两件事：
1. **空闲电平是 0**，所以极性默认取 **「高有效」**（触发时引脚被拉起 → 判为接收中）。
   若你的接法确实是「触发时把引脚拉低」，在设置页把极性切回「低有效」即可，**无需改代码/重启**。
2. **3.3 V 数字输入判据 VIL≈0.99 V、VIH≈2.31 V**。你描述的「触发时被光耦拉到约 2.7 V」
   —— 2.7 V **高于** VIH(2.31 V)，会被读成 **高电平**，正好与「高有效」判定一致；
   但若接法是**空闲 3.3 V、触发拉到 2.7 V**，则两次都读 1，软件无法区分。
   **请按下面步骤确认一次**：

   1. 打开「设置与校准 → BUSY 接收状态」卡片（2 s 自动刷新）；
   2. 电台静噪关闭（无信号）时记录 `原始电平`；
   3. 让接收机收到信号（或短接控制板 BUSY 到地/12 V），观察 `原始电平` 与 **`电平变化次数`**；
   4. - `电平变化次数` 有增长 → 接线有效，按实测极性选「高有效/低有效」即可；
      - `电平变化次数` 始终不变 → 引脚没动，需要按设计补 **GPIO 侧 10 k 上拉到 3.3 V**，
        或加大光耦驱动电流 / 在 GPIO 侧加对地下拉（使其可靠跨过 0.99 V / 2.31 V 门限）。
