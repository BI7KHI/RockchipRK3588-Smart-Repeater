## 三、具体做了哪些改动

### 1. 训练集高频衰减（`training_v2/hf_prep.py`）
对原始 44.1kHz 素材施加：
- 高架衰减：2.8 kHz 以上 −6 dB（Q=0.6）
- 两级低通：7.2 kHz + 9.0 kHz（2 阶 Butterworth）

处理后再用 `scipy.resample_poly` 做**抗混叠**重采样到 22050 Hz，写入 `rosmontis_dataset_hf`。

### 2. 重训（`training_v2/train_config_hf.yaml`）
- 基座仍是 `zh_CN-huayan-medium`，`warmstart_ckpt` 非严格加载（784/784 参数命中）
- 学习率由 2e-4 降到 **1.5e-4**，判别器学习率 1e-4 降到 **5e-5**（抑制 GAN 伪影）
- batch 4 / 16-mixed / 22050 Hz，训练 **150 epoch（约 1300 step）**
- val_mel：最优 **0.0750**（epoch 88），次优 0.0886（epoch 130）、0.1012（epoch 59）、0.1102（epoch 142）

> 为什么只训 150 epoch：上一版 300 epoch 后期 val_mel 反而变差（末轮 0.3748），
> 而"弹簧音"多来自小数据下 GAN 训练过久；本轮在 val_mel 收敛后即停止，更稳。

### 3. 输出端低通 + 去齿音（`training_v2/postfilter.py`）
- **动态去齿音**：4500–9000 Hz 分频段包络检测，最大衰减 5 dB，门限 = 本句 75 分位 +4 dB
- **低通**：8 kHz（2 阶）
- **高架衰减**：3.5 kHz 以上 −2 dB
- 已对 7 条试听样例实测：触发帧占 6~15%，最大衰减 3~5 dB

## 五、板端部署 & 后处理开关

1. 网页 `http://<板卡IP>:8080` → 语音合成 → 上传音色包 → 填音色 ID
2. 后处理接入：见 `C:\Users\Admin\Desktop\ELF2\智能中继架构\web_client\板端TTS后处理接入说明.md`
   （`postfilter.py` 已放在该目录，只依赖 numpy，板端无 scipy 也能跑；
   实测与 scipy 版本输出差异 ≤1 LSB，RK3588 上 4 秒音频耗时 <0.8 秒）
3. **v2 音色包 + 默认后处理参数（lp=8000, shelf=-2, deess=5）** 正好落在 huayan 同亮度，
   建议就用这组参数

## 六、如果还想继续调
- 仍嫌亮/刺：把 `--lp` 降到 7000、`--shelf-db` 改 −3、`--deess-max` 提到 6（无需重训，只改板端环境变量）
- 觉得闷：把 `RELAY_TTS_FILTER=0` 关掉后处理（v2 原声 2294 Hz，仍比 v1 暗很多）
