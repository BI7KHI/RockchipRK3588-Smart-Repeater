# ELF2 40P/20P 管脚功能分配和硬件连线方案

> 适用硬件：ELF2 / RK3588 开发板 + 第三方中继控制板 + 2×GM3188
> 重要原则：40Pin 信号为 **3.3V 电平**，20Pin 的 SARADC 输入为 **1.8V 满量程**；严禁把 5V/12V 直接接入 GPIO 或 ADC。
> 40Pin 网络名规则：`3576引脚--3588引脚--底板功能`，本项目按中间 RK3588 网络使用。
> 完整接线核对图见：`智能中继架构/ELF2_40P20P_接线核对图.svg`

---

## 1. 连接需求汇总

| 功能 | 方向 | 推荐接口 | 说明 |
|---|---|---|---|
| 气象站 RS485 | 双向 | P26 40Pin UART9 | `/dev/ttyS9`，Modbus RTU，9600 8N1 |
| PC0-PC3 频率选择 | RK3588→控制板 | P26 4×GPIO | 4 位编码，最多 16 信道 |
| PTT 发射使能 | RK3588→控制板 | P26 1×GPIO | 经隔离/驱动后接控制板 PTT |
| BUSY 接收状态 | 控制板→RK3588 | P26 1×GPIO | 经隔离/分压后输入 |
| 电池电压采集 | 模拟→ADC | P28 SARADC_VIN4 | 分压到 ≤1.8V |
| 光伏电压采集 | 模拟→ADC | P28 SARADC_VIN6 | 分压到 ≤1.8V |
| 音频采集 | 控制板→ELF2 | 3.5mm AUX MIC | RX 音频/DF/SPK 经衰减隔离 |
| 音频输出 | ELF2→控制板 | 3.5mm AUX HP | TTS/转发/VOIP 经衰减隔离 |
| USB 摄像头 | USB | USB-A | UVC 摄像头，建议 USB2.0 或 USB3.0 独立口 |

| 5 | SARADC_VIN6 | ADC | **光伏电压采集** |

| 7 | SARADC_VIN7 | ADC | 预留 |

### 20Pin ADC 分压设计

SARADC：12bit，0~4096，满量程 1.8V。

| 采集对象 | P28 引脚 | 建议分压 | 最大输入（到 1.8V 对应） | 说明 |
|---|---|---|---|---|
| 电池电压 | 6（SARADC_VIN4） | R_top=100k，R_bottom=12k | 约 16.8V | 12V 电池/充电最高约 14.6V，留有余量 |
| 光伏电压 | 5（SARADC_VIN6） | R_top=100k，R_bottom=5.6k | 约 33.9V | 以 12V 光伏板 Voc 约 22V 为例，余量足够 |

计算：

```text
V_adc = V_in × R_bottom / (R_top + R_bottom)
```

建议在每个 ADC 节点增加：

```text
V_in ── R_top ──┬── 1k ── SARADC_VINx
                │
              R_bottom
                │
               GND
```

并在 ADC 节点加：
- 100nF 到 GND；
- BAT54S 或 1.8V TVS 钳位；
- 100Ω~1k 串联限流；
- 若需要更高精度，使用轨到轨运放缓冲（如 TLV9001，供电 1.8V）。

## 4. 外部硬件连接方案

### 4.1 第三方中继控制板

```text
ELF2 P26-29  GPIO3_B6 ──► 电平转换/光耦 ──► 控制板 PC0
ELF2 P26-31  GPIO3_A6 ──► 电平转换/光耦 ──► 控制板 PC1
ELF2 P26-33  GPIO3_A4 ──► 电平转换/光耦 ──► 控制板 PC2
ELF2 P26-35  GPIO3_A0 ──► 电平转换/光耦 ──► 控制板 PC3
ELF2 P26-32  GPIO3_A1 ──► PTT 驱动/光耦 ──► 控制板 PTT
ELF2 P26-36  GPIO3_A5 ◄── BUSY 隔离/分压 ◄── 控制板 BUSY
ELF2 P26-6/9/30/34/39  GND ─────────────── 控制板 GND
```

- PC0-PC3 建议使用 **4 通道光耦隔离板**（如 PC817×4）或 74LVC245/ULN2003 电平转换。
- PTT 建议使用 **光耦或 NPN 开集电极驱动**，禁止 GPIO 直接接 5V/12V PTT 输入。
- BUSY 建议使用 **光耦输入**：控制板 BUSY → 限流电阻 → 光耦 LED，光耦输出 → ELF2 GPIO，GPIO 侧 10k 上拉到 3.3V，并联 100nF 去抖。
- 若控制板信号本身就是 3.3V，可直连，但仍建议串联 100Ω 电阻并加 TVS/RC 滤波。

### 4.2 RS485 气象站

```text
ELF2 P26-8  UART9_TX ──► TTL-RS485 DI
ELF2 P26-10 UART9_RX ◄── TTL-RS485 RO
ELF2 P26-26 GPIO3_D2 ──► TTL-RS485 DE/RE（可选）
ELF2 P26-1  VCC_3V3  ──► TTL-RS485 VCC（3.3V 模块）
ELF2 P26-6  GND      ──► TTL-RS485 GND
```

RS485 侧：

```text
TTL-RS485 A ────── 气象站 A
TTL-RS485 B ────── 气象站 B
屏蔽层单端接 GND / 机壳地
```

- 使用双绞屏蔽线；
- 总线末端加 120Ω 终端电阻（波特率 9600、短距离可不加，长线建议加）；
- A/B 加 TVS（如 SMBJ6.5CA）和共模电感；
- 使用 3.3V 的 MAX3485/SP3485 或隔离型 ADM2483；
- 如果模块是 5V 供电，务必确认 RO 输出不超过 3.3V，否则加电平转换。
- Linux 设备：`/dev/ttyS9`，9600 8N1；RS485 半双工由 GPIO3_D2 或自动方向模块控制。

### 4.3 音频接口

ELF2 板载 3.5mm CTIA 四段耳机/MIC 座，建议增加一块“音频隔离/衰减板”：

```text
控制板 SPK/DF ──► 衰减/隔离 ──► ELF2 3.5mm MIC
ELF2 3.5mm HP ──► 衰减/隔离 ──► 控制板 MIC
```

推荐电路：

- RX 音频（SPK/DF）：
  - 先区分 SPK 功放输出和 DF 解调输出；
  - SPK 先经 10:1 或 20:1 电阻衰减；
  - 再经 600:600Ω 音频隔离变压器；
  - 10uF 无极性电容耦合到 3.5mm MIC；
  - 并联双向 TVS/限幅，防止过压。
- TX 音频（ELF2 耳机输出 → 控制板 MIC）：
  - 3.5mm Tip/Ring1 输出经 10uF 隔直；
  - 10k/1k 或 100k/10k 衰减；
  - 音频隔离变压器；
  - 送入控制板 MIC。
- 地线：
  - 音频地与控制板地共地，但建议单点接地；
  - 屏蔽线屏蔽层单端接地；
  - 音频线远离天线、功放和 PTT 驱动线。
- 若控制板 MIC 输入带偏置，必须在 ELF2 输出侧加隔直电容，避免直流倒灌。

> 3.5mm 座 CTIA 标准：Tip=左声道，Ring1=右声道，Ring2=GND，Sleeve=MIC。实际以 ELF2 原理图/实测为准。

### 4.4 USB 摄像头

```text
USB 摄像头 ──► ELF2 USB-A 口（UVC）
```

- 优先使用 USB2.0 或 USB3.0 独立口；
- 摄像头供电不足时使用带电源 HUB；
- 数据线加磁环，远离射频天线和音频线；
- 如果只是拍照/短视频，可用 USB；若做实时视觉，确认带宽和 NPU 资源。

## 6. 注意事项与检查清单

### 6.1 电气安全

- [ ] 40Pin GPIO 只能接 3.3V 电平，禁止接 5V/12V。
- [ ] 20Pin SARADC 输入禁止超过 1.8V。
- [ ] 所有外部模块必须共地，音频/射频地单点连接。
- [ ] PC0-PC3、PTT、BUSY 建议全部光耦隔离，至少使用电平转换。
- [ ] PTT 上电默认必须处于释放状态，防止误发射。
- [ ] BUSY 输入加 10k 上拉和 100nF 去抖。
- [ ] RS485 A/B 加 TVS，长线加 120Ω 终端电阻。
- [ ] ADC 分压电阻用 1% 金属膜电阻；光伏高压端注意爬电距离和绝缘。
- [ ] 功放/电台天线与 ELF2、音频线、GPIO 线保持距离。

### 6.2 软件 GPIO 对应

- [ ] 确认 ELF2 设备树已把对应 pinmux 配置为 GPIO，而不是 SPI/I2C/UART 功能。
- [ ] 使用 `gpiod`/`libgpiod` 或 `cat /sys/kernel/debug/gpio` 核对 GPIO 编号。
- [ ] 40Pin 上标称的 GPIO 名与 Linux 编号不是一对一，必须以实际 `gpiochip` 行为为准。
- [ ] PC0-PC3 的编码顺序必须与控制板手册一致。
- [ ] PTT/BUSY 的有效极性必须与实际硬件一致（高有效/低有效）。
- [ ] UART9 使用 `/dev/ttyS9`，与调试串口 UART2 区分。
- [ ] ADC 读取后按分压比换算真实电压，并做软件滤波。

### 6.3 建议的默认状态

| 信号 | 上电默认 | 原因 |
|---|---|---|
| PC0-PC3 | 全部低电平/高阻 | 避免选中未知信道 |
| PTT | 释放/高阻 | 防止误发射 |
| BUSY | 输入上拉 | 未收到信号时保持稳定 |
| RS485_DE | 接收态 | 避免占用总线 |
| 音频通道 | 静音/隔直 | 防止冲击声 |
