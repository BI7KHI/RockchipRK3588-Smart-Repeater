# ELF2 3.5mm 耳机接口音频输入原理图结论

## 1. 结论

ELF2 的 3.5mm 音频座（位号 P21，`PJ-3536X`）**支持音频输入（MIC 录音）**，并且是四段式 CTIA 接口，支持：

- 左右双声道耳机播放
- MIC 录音

不是只有耳机输出。

## 2. 原理图依据

从 `ELF 2 & ELF 2_Lite V1.3原理图.PDF` 第 9 页 `Audio.SchDoc`：

- 3.5mm 座 P21 的 PIN1 网络为 `LMIC_P`，即左声道 MIC 输入。
- 耳机输出为：
  - `HP_L`
  - `HP_R`
- 板载麦克风为 P20，网络为 `RMIC_P`，即右声道 MIC 输入。
- 音频 Codec U17 为 `NAU88C22YG`。
- MIC 输入经过耦合电容进入 U17：
  - `LMIC_P` → LMICP/LMICN
  - `RMIC_P` → RMICP/RMICN
- `MICBIAS` 通过 2.2k 电阻给麦克风提供偏置。

硬件设计教程也明确说明：

> ELF2 默认 3.5mm 音频插座采用 CTIA 标准，支持左右双声道播放和 MIC 录音；插入 OMTP 耳机可能出现放音和录音失效。

## 3. 为什么之前采集到的是板载麦克风

NAU88C22 内部有输入源开关：

```text
Main Mic Switch
Headset Mic Switch
```

当前板卡默认状态为：

```text
Main Mic      [on]
Headset Mic   [off]
```

所以 `arecord` 默认采集到的是板载麦克风 P20，而不是 3.5mm 耳机麦克风。

## 4. 切换到 3.5mm 耳机麦克风

```bash
amixer -c 1 sset 'Manual' 2>/dev/null || true

# 选择 3.5mm 耳机麦
amixer -c 1 sset 'Headset Mic' on
amixer -c 1 sset 'Main Mic' off

# 如果需要回到板载麦
# amixer -c 1 sset 'Main Mic' on
# amixer -c 1 sset 'Headset Mic' off
```

然后采集：

```bash
arecord -D plughw:CARD=rockchipnau8822,DEV=0 \
  -f S16_LE -r 16000 -c 2 -t raw /tmp/mic_stereo.raw
```

- 左声道：3.5mm 耳机麦克风（LMIC_P）
- 右声道：板载麦克风（RMIC_P）

网页控制中心中已提供：

- 输入源：板载 MIC / 3.5mm 耳机 MIC
- 监听声道：左声道（3.5mm 耳机麦）/ 右声道（板载麦）/ 混合
- PGA 前级增益
- ADC 数字增益
- +20dB PGA Boost
- L2/R2 增强
- Aux Boost

## 5. 推荐调试参数

如果 3.5mm 耳机麦克风声音小、底噪大，可优先尝试：

```text
输入源：3.5mm 耳机 MIC
监听声道：左声道（3.5mm 耳机麦）
PGA：60~80%
ADC：100%
+20dB PGA Boost：开启
L2/R2 增强：0~20%
Aux Boost：0%
```

注意：

- PGA 过高会同时放大底噪。
- 耳机必须是 CTIA 标准四段式。
- 如果耳机是 OMTP 标准，MIC 可能无法正常输入。
- 如果仍然很小，检查耳机插入深度、MICBIAS 和焊接。
