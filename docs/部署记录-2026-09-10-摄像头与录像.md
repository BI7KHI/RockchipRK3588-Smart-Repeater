# ELF2 USB2.0 摄像头、录像、OSD、RTMP 部署记录

## 1. 硬件识别

USB2.0 免驱摄像头：

```text
lsusb: 1bcf:2281 Sunplus Innovation Technology Inc. SPCA2281 Web Camera
```

V4L2 节点：

```text
/dev/video21   视频采集（MJPG）
/dev/video22   元数据
```

支持格式：

```text
1920x1080 MJPG @ 30fps
```

当前默认使用：

```text
设备：/dev/video21
分辨率：640x480
帧率：15fps
```

## 2. 架构

UVC 摄像头只能被一个进程独占打开，因此采用：

```text
单进程 ffmpeg 采集 /dev/video21
        ↓
输出连续 JPEG 帧（image2pipe）
        ↓
Python CameraService 分发
        ├─ 网页 MJPEG 预览
        ├─ 循环录像转码
        ├─ 单独录像转码
        ├─ RTMP 推流
        └─ 抓拍
```

录像/推流时从 CameraService 的帧队列读取，不再单独打开摄像头，避免：

```text
Device or resource busy
```

## 3. 已实现功能

### 预览

- 网页摄像头页显示 MJPEG 实时画面
- 浏览器实测自然尺寸：

```text
640x480
```

### 录像

- 循环录像：
  - 可设置分段时长（默认 60s）
  - 可设置存储上限
  - 可设置最大文件数
  - 自动清理最旧文件
- 单独录像：
  - 手动开始
  - 手动停止并保存 MP4
- 录像列表：
  - 文件名
  - 类型（循环/手动）
  - 大小
  - 时间
  - 播放 / 删除

实测：

```text
循环录像文件: loop_20260910_183249.mp4
H.264 640x480
可正常生成并删除
```

### OSD

- 网页预览使用客户端 HTML 叠加：
  - 自定义文字
  - 实时时间
  - 左上/右上/左下/右下
- 录像/RTMP 使用 ffmpeg `drawtext` 烧录：
  - 支持自定义英文文字
  - 支持 `%{localtime}` 实时时间
  - 支持字号、位置、颜色

### RTMP 推流

- 支持设置 RTMP 地址
- 支持开始/停止推流
- 推流同样使用 CameraService 帧队列，不单独打开摄像头
- 已做进程启动/停止测试
- 实际推流需要用户提供可用 RTMP 服务器

## 4. 录像存放

默认：

```text
/www/camera_recordings/
```

文件命名：

```text
loop_YYYYMMDD_HHMMSS.mp4
manual_YYYYMMDD_HHMMSS.mp4
snapshot_YYYYMMDD_HHMMSS.jpg
```

可通过网页设置页修改录像目录。

## 5. 主要 API

| API | 说明 |
|---|---|
| `/api/camera/status` | 状态、设置、录像列表 |
| `/api/camera/stream` | MJPEG 预览 |
| `/api/camera/settings` | 摄像头/OSD/录像/RTMP 设置 |
| `/api/camera/snapshot` | 抓拍 |
| `/api/camera/record/manual/start` | 开始单独录像 |
| `/api/camera/record/manual/stop` | 停止并保存单独录像 |
| `/api/camera/loop/start` | 开始循环录像 |
| `/api/camera/loop/stop` | 停止循环录像 |
| `/api/camera/rtmp/start` | 开始 RTMP 推流 |
| `/api/camera/rtmp/stop` | 停止 RTMP 推流 |
| `/api/camera/recordings` | 录像列表 |
| `/api/camera/recordings/<file>` | 播放/删除录像 |

## 6. 注意事项

1. 一个 UVC 摄像头只能有一个采集进程，不能同时用两个 ffmpeg 打开 `/dev/video21`。
2. 默认 640x480@15 是为了和 NPU LLM 同时运行，降低 CPU/内存占用。
3. 录像使用 H.264 转码；如果 CPU 占用高，可降低分辨率/帧率。
4. RTMP 推流需要外网可达的 RTMP 服务器。
5. OSD 自定义文字当前仅支持英文/数字/常用符号（DejaVu 字体）；中文 OSD 需要替换中文字体。
6. 预览停止后，`arecord` 与摄像头采集进程都会释放。
