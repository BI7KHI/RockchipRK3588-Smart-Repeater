## 二、试听建议顺序

1. 先听 `samples/base/01_中继测试.wav`（原始 huayan 音色）
2. 再听 `samples/ft_best/01_中继测试.wav`（音色包 A）
3. 最后听 `samples/ft_final/01_中继测试.wav`（音色包 B）
4. 07_设备播报 是最长的一条（约 15 秒），用于检验长句稳定性

## 三、板端部署

1. 浏览器打开 `http://<板卡IP>:8080` 并登录
2. 进入「语音合成 / TTS」页面 → 「上传音色包」
3. 选择上面两个 zip 之一，音色 ID 填对应名字
4. 上传后板端目录为 `/opt/ai/voices/<ID>/model.onnx` + `model.onnx.json`
5. 在语音页面把音色切换为该 ID，输入文本即可离线合成（板端 PTT 会自动联动发射）

## 四、训练过程摘要

- 数据：`Rosmontis_训练集` 38 条 wav（原始 44.1kHz），共 538.4 秒；转写 38/38 全部匹配
- 基座：`zh_CN-huayan-medium`（Piper VITS, 22050Hz, medium）
- 框架：piper1-gpl / `piper-tts 1.8.0`，PyTorch 2.14+cu130，单卡 4070 Laptop
- 参数：batch=4，lr=2e-4，precision=16-mixed，300 epoch（约 2400 step，用时约 34 分钟）
- `val_mel` 曲线（4 条验证集）：best **0.1308**（epoch 88）、次优 **0.1380**（epoch 267）、
  末轮 0.3748；VITS 的 val_mel 在小型验证集上抖动较大，**最终音质请以试听为准**
- 训练中做了 3 处关键修复：monotonic_align Cython 扩展缺失补编译；旧 checkpoint 扁平
  hyper_parameters 改用 `model.warmstart_ckpt` 非严格加载（784/784 参数命中）；
  torch 2.14 的 ONNX 导出强制走 legacy TorchScript exporter

## 五、已知说明 / 注意事项

1. **音色偏亮、气声较重**：源素材本身频谱很亮（44.1kHz 原文件谱质心约 5.2kHz，
   11kHz 以上能量占 ~12%），模型忠实学到了这个特征，因此比 huayan 原声明显更"亮/气"。
   如果试听后觉得偏刺耳，可以：① 对训练集做轻度高频衰减后重训；② 合成时加大
   `--length-scale`、或对输出做低通/去齿音后处理。
2. 数据集重采样：本次用原始 44.1kHz 文件交给 librosa/soxr 做抗混叠重采样（此前一版
   直接隔点抽取会产生折返噪声，已废弃并重新训练）。
3. 端侧兼容：`model.onnx.json` 的 `phoneme_id_map` 是训练侧 espeak `cmn` 生成的 166 项，
   包含板端 huayan 音色的全部 152 项且 id 完全一致，后 14 项为该版本 espeak 的额外音素，
   不会影响板端（板端 piper 只需 `model.onnx` + `model.onnx.json` + 自带 espeak-ng-data）。
