## 2. 已实现功能

### 2.1 登录与安全

- 登录页 + 退出
- 登录页不显示默认管理员账号、密码或密码提示；初始凭据由部署方掌握，首次登录后请立即修改
- 密码使用 Werkzeug PBKDF2 哈希存储
- Flask Session 签名 Cookie，密钥 `/www/instance/secret.key`（0600）
- 所有写 API 要求 `X-CSRF-Token`
- 用户管理、设置、校准仅管理员可访问
- SQLite WAL + NORMAL 同步，低开销

### 2.2 用户管理

- 管理员添加用户
- 删除用户（默认 Admin 不可删除，自己不可删除）
- 管理员重置用户密码
- 用户修改本人密码
- 已测试普通用户访问管理员 API 返回 403

### 2.3 总览

- 电池电压：`SARADC_VIN4` → `/sys/bus/iio/devices/iio:device0/in_voltage4_raw`
- 光伏电压：`SARADC_VIN6` → `/sys/bus/iio/devices/iio:device0/in_voltage6_raw`
- CPU 百分比、Loadavg、内存、温度、运行时间

### 2.4 电压校准

- 每个通道支持：
  - 零点 `zero_raw`
  - 倍率 `multiplier`
- 公式：
  ```text
  voltage = max(0, (raw - zero_raw) × multiplier)
  ```
- 默认倍率：
  - 电池 100k/12k 分压：`0.00410156 V/raw`
  - 光伏 100k/5.6k 分压：`0.0082878 V/raw`
- 页面可保存，API 已测试通过

### 2.5 LLM 对话

- 提供商切换：
  - 本地模型：默认 `http://127.0.0.1:8001/v1`
  - 外部 API：任意 OpenAI 兼容 Base URL
- 模型名、API Key 可在设置页维护
- 支持非流式 + SSE 流式输出
- 已用本地 Qwen2.5-1.5B RKNPU 服务在网页中测试对话成功

### 2.6 网页对讲

- 前端支持浏览器麦克风采集并编码 WAV
- 由于浏览器安全上下文限制，局域网 HTTP 访问时麦克风可能不可用；已提供：
  - 上传 WAV 文件测试
  - 播放测试音按钮
- 录音保存到 `/www/recordings/`
- 自动播放到：
  ```text
  plughw:CARD=rockchipnau8822,DEV=0
  ```
- 录音记录列表和重放
- 已通过 egobrowser 上传 WAV 并在网页中看到录音记录（1000 ms / 31.3 KB）

### 2.7 系统全局音量

- 设置 / 校准页新增全局音量控件：
  - 0~100% 滑条
  - 全局静音开关
  - 应用音量按钮
  - 测试提示音按钮
  - 刷新状态按钮
- 控制 NAU88C22 `Headphone` 与 `Speaker` 输出，作用于 3.5mm AUX。
- 后端接口：
  - `GET /api/audio/volume`
  - `POST /api/audio/volume`
- 音量与静音状态保存到 SQLite，服务重启后自动恢复。
- 实测：设置 55% → 重启页面后仍为 55%；静音后 Headphone/Speaker 的 Playback 状态变为 off。

### 2.8 开发板耳机输入监听测试

- 原理图确认：ELF2 3.5mm 音频座 P21 支持 MIC 输入，PIN1 为 `LMIC_P`。
- 板载 MIC P20 为 `RMIC_P`。
- NAU88C22 输入源由 `Main Mic` / `Headset Mic` 开关选择。
- 服务端通过 `arecord -D plughw:CARD=rockchipnau8822,DEV=0 -f S16_LE -r 16000 -c 2 -t raw -` 采集立体声。
- 网页“网页对讲”页新增：
  - 输入源：板载 MIC / 3.5mm 耳机 MIC
  - 监听声道：左（3.5mm）/ 右（板载）/ 混合
  - PGA 前级增益 0~100%
  - ADC 数字增益 0~100%
  - +20dB PGA Boost
  - L2/R2 增强
  - Aux Boost
  - 开始采集 / 停止采集
  - 实时 Level / RMS / Peak / dBFS / L-RMS / R-RMS 显示
  - 开启网页监听 / 停止网页监听
- 后端接口：
  - `GET/POST /api/mic/settings`
  - `POST /api/mic/capture/start`
  - `POST /api/mic/capture/stop`
  - `GET /api/mic/level`
  - `GET /api/mic/stream`（`audio/L16`, 16000 Hz, mono）
- 实测：
  - 输入源切换成功
  - 立体声采集左右声道均可计算电平
  - 约 1 秒流读取到约 37~41 KB PCM
  - 网页监听成功开启并停止
  - 停止采集后电平归零

### 2.9 摄像头 / 录像 / OSD / RTMP

- 识别 USB2.0 免驱摄像头：Sunplus SPCA2281，节点 `/dev/video21`。
- 单进程 ffmpeg 采集，Python CameraService 分发帧队列：
  - 网页 MJPEG 实时预览
  - 循环录像
  - 单独录像
  - RTMP 推流
  - 抓拍
- 网页摄像头页支持：
  - 开始/停止预览
  - 抓拍
  - 循环录像开始/停止、分段时长、容量上限、最大文件数
  - 单独录像开始/停止并保存
  - RTMP 推流地址与开始/停止
  - OSD 文字、时间、位置、字号
  - 录像列表、播放、删除
- 默认录像目录：`/www/camera_recordings/`
- 实测预览 640x480，H.264 录像可生成/播放/删除，RTMP 进程可启动/停止。
- 详细记录见：`智能中继架构/部署记录-2026-09-10-摄像头与录像.md`
