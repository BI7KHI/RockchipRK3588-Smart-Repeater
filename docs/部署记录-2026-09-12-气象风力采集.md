# ELF2 气象风力采集部署记录（RS485 / Modbus RTU）

## 1. 当前硬件连接

```text
ELF2 P26-8  UART9_TX  → MAX3485 TTL 侧 TXD/DI
ELF2 P26-10 UART9_RX  ← MAX3485 TTL 侧 RXD/RO
ELF2 P26-6  GND       → MAX3485 GND
MAX3485 A/B            → 风力变送器 RS485 A/B
```

当前使用 MAX3485 自动方向收发模块，无需 DE/RE 控制，也不在网页/API 中提供 DE GPIO 与有效电平设置。UART9 只连接 TX/RX/GND。

## 2. 软件实现

新增气象服务：

```text
/www/weather_service.py
```

后台线程按 `weather_poll_interval` 周期读取 Modbus RTU，并写入 SQLite：

```text
weather_readings
```

字段：

```text
id, ts, ts_epoch, wind_speed, raw, unit, error
```

默认 Modbus 参数：

```text
串口：/dev/ttyS9
波特率：9600
数据位：8
校验：无
停止位：1
从站地址：1
功能码：03
寄存器：0x0000
读取数量：1
倍率：0.1
轮询间隔：2s
单位：m/s
```

## 5. 当前实测结果（通讯已恢复正常）

服务状态：

```text
weather_service running = true
error_count = 0
```

实际收发帧：

```text
TX: 01 03 00 00 00 01 84 0A
RX: 01 03 02 00 00 B8 44
```

CRC 校验通过，`raw = 0x0000`，按倍率 0.1 换算当前风速为 `0.0 m/s`。

说明：

- UART9 已打开，9600 8N1；
- Modbus 请求帧与响应帧均正确；
- 响应格式为：

  ```text
  01 03 02 XX XX CRC_LO CRC_HI
  风速 = (XX XX) / 10.0 m/s
  ```

- 之前出现的 `RX: 00` 是空闲/噪声破帧，现已由优化后的扫描+CRC 解析逻辑排除；
- 当前读数为 0 m/s 可能是真实无风，也可能传感器未转动/量程较小，需要结合实际环境判断。

## 6. 常见问题排查

1. **A/B 极性**
   - RS485 A/B 接反是最常见原因；
   - 可先对调 A/B 测试。

2. **方向控制**
   - 当前使用 MAX3485 自动方向模块，无需 DE/RE GPIO，也不在网页/API 中配置；
   - 若更换为需要手动方向的模块，应改为硬件自动方向方案或在系统层单独处理，当前软件不提供 DE 配置项。

3. **传感器供电**
   - 风力变送器是否已接入 12V/24V？
   - 变送器 RS485 A/B 是否与采集模块共地/正确接线？

4. **串口配置**
   - 波特率是否为 9600？
   - 从站地址是否为 1？
   - 寄存器地址是否为 0x0000？
   - 功能码是 03 还是 04？
   - 可在“设置 / 校准”页逐项调整并保存，轮询会自动生效。

5. **P26 接线**
   - P26-8 对应 UART9_TX；
   - P26-10 对应 UART9_RX；
   - 不要与 P26 其他功能混接。

6. **软件验证**
   - 可使用诊断接口发送自定义帧：
     ```text
     POST /api/weather/serial_debug
     {"tx_hex": "010300000001840a", "wait_ms": 800}
     ```
   - 若返回 `rx_hex` 为空或长度异常，优先排查硬件、极性与供电。

## 7. 数据维护

- 默认保留 90 天历史数据，可通过 `weather_service.cleanup()` 清理。
- 日期查询支持历史回放。

## 8. 翻斗式降水量传感器接入（2026-09-13）

### 8.1 总线与地址

- 降水量传感器与风力变送器共用 UART9 / RS485 总线；
- 通信参数：9600 8N1，Modbus RTU，功能码 03；
- 扫描发现从站地址：`23`（0x17）；
- 风力变送器地址保持 `1`；
- 自动方向 MAX3485 模块，无需 DE/RE 控制。

实测帧：

```text
TX: 17 03 00 00 00 01 86 FC
RX: 17 03 02 00 00 F1 87
```

当前累计降水量 `raw = 0`，按倍率 `0.1 mm/raw` 换算为 `0.0 mm`。

### 8.2 软件新增

- 新表：`rain_readings(id, ts, ts_epoch, rain_total, raw, unit, error)`；
- 新 CSV：`/www/weather_csv/rain_YYYY-MM-DD.csv`；
- 轮询线程在每次风力采集后追加读取一次雨量计；
- 小时降水量由累计值差分计算，支持设备清零/重启导致的累计值归零；
- 网页新增：
  - 实时降水量、今日累计、最近 1 小时降水、最大小时；
  - “每小时降水量统计”柱状图 + 24 小时表格；
  - 支持按日期查询与导出小时 CSV；
- 设置页新增“降水量传感器设置（翻斗式）”：启用、从站地址、功能码、寄存器、读取数量、倍率。
