# ELF2 PTT GPIO3_A1 控制部署记录（2026-09-13）

## 1. 目标

当开发板输出音频（TTS 朗读、网页对讲回放、测试音）时，自动将 PTT 信号拉高；
音频结束后拉低，用于控制电台/中继板 PTT。

## 2. 引脚与电平

```text
ELF2 P26-32  GPIO3_A1  ->  PTT
Linux 全局 GPIO：gpiochip3 base 96 + A1(1) = 97
方向：输出
有效电平：高电平（RELAY_PTT_ACTIVE_HIGH=1）
```

## 3. 软件实现

`/www/app.py` 中新增：

- `_ptt_ensure()`：导出 GPIO97 并设置为输出；
- `_ptt_set_level()`：写 `/sys/class/gpio/gpio97/value`；
- `_ptt_retain()` / `_ptt_release()`：引用计数；
- `ptt_audio_hold()`：音频播放上下文；
- `ptt_status()`：查看 GPIO、当前电平、引用计数、错误。

音频播放接入点：

- `play_audio_async(path, ptt=True)`：TTS 整段朗读；
- `_play_audio_wait()`：流式 TTS 分片播放。

说明：网页对讲回放、测试音默认不触发 PTT；如后续需要“所有音频输出均触发 PTT”，可把对应 `play_audio_async()` 调用改为 `ptt=True`。

释放策略：

- 音频结束引用计数归零后，延迟 0.8 s 再拉低；
- 用于桥接流式 TTS 片段之间的间隙，避免 PTT 频繁抖动。

## 4. GPIO 权限准备

新增：

```text
www/ptt_gpio_prepare.sh      -> /usr/local/sbin/elf2-ptt-gpio.sh
www/elf2-ptt-gpio.service    -> /etc/systemd/system/elf2-ptt-gpio.service
```

`elf2-ptt-gpio.service` 以 root 运行一次：

1. export GPIO97；
2. 设置 direction=out、value=0；
3. chown elf:elf、chmod ug+rw；
4. `relay-web.service` 启动前执行。

## 5. 环境变量

```text
RELAY_PTT_GPIO=97
RELAY_PTT_ACTIVE_HIGH=1
```

## 7. 注意事项

- 若系统内核未启用 `/sys/class/gpio`，需改用 libgpiod 或设备树 pinctrl 方案；
- GPIO3_A1 当前必须未被其他外设复用；
- PTT 高电平期间会控制电台发射，调试时应确保音频/负载正确连接；
- 上电初始化会主动拉低，避免上电即发射。

### 8.3 权限持久化

新增 udev 规则：

```text
/etc/udev/rules.d/99-elf2-ptt.rules
```

内容：

```text
SUBSYSTEM=="gpio", KERNEL=="gpio97",
RUN+="/bin/sh -c 'for f in direction value active_low edge; do chown elf:elf /sys/class/gpio/gpio97/$f 2>/dev/null; chmod ug+rw /sys/class/gpio/gpio97/$f 2>/dev/null; done'"
```

`elf2-ptt-gpio.service` 增加 `ExecStartPost`：

```text
udevadm settle
chown/ chmod direction、value、active_low、edge 为 elf:elf / ug+rw
```

确保每次启动或重新导出 GPIO 后，relay-web 都有写权限。

## 9. eth0 100 Mbps 持久化

开发板链路协商异常，已将 NetworkManager 连接配置固定为 100 Mbps 全双工：

```text
nmcli con mod "Profile 1" \
  802-3-ethernet.speed 100 \
  802-3-ethernet.duplex full \
  802-3-ethernet.auto-negotiate no
nmcli device reapply eth0
```

配置文件 `Profile 1.nmconnection` 中已显式包含：

```ini
[ethernet]
auto-negotiate=false
duplex=full
speed=100
```

> 注意：如果只设置 speed/duplex，但 `auto-negotiate` 仍为 true，NetworkManager 会忽略 speed/duplex；
> 必须同时写入 `auto-negotiate=false`，或由 dispatcher 脚本强制 `ethtool`。

另外增加了 NetworkManager dispatcher 兜底脚本：

```text
/etc/NetworkManager/dispatcher.d/90-elf2-eth0-100m
```

内容：

```sh
#!/bin/sh
IFACE="$1"
ACTION="$2"
[ "$IFACE" = "eth0" ] || exit 0
[ "$ACTION" = "up" ] || exit 0
/usr/sbin/ethtool -s eth0 speed 100 duplex full autoneg off
exit 0
```

该脚本在 eth0 每次 `up` 事件时强制执行 100M 全双工、关闭自协商。

验证：

```text
ethtool eth0:
  Advertised link modes:  100baseT/Full
  Speed: 100Mb/s
  Duplex: Full
  Auto-negotiation: off
```

重启测试：

```text
reboot 后 dmesg 仅出现：
  rk_gmac-dwmac ... eth0: Link is Up - 100Mbps/Full - flow control rx/tx

nmcli:
  802-3-ethernet.speed: 100
  802-3-ethernet.duplex: full
  802-3-ethernet.auto-negotiate: no
```

结论：已经验证重启后仍为 100 Mbps 全双工，不再回到 1 Gbps 反复掉线。
